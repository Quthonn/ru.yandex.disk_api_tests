# ru.yandex.disk_api_tests
## Запуск автотестов

1. Получите токен своего аккаунта Яндекс Диска по [инструкции Яндекса](https://yandex.ru/dev/disk-api/doc/ru/concepts/quickstart#quickstart__oauth) и скопируйте его.
2. Создайте файл `.env` в корне проекта.
3. Добавьте в него переменную `TOKEN` и вставьте свой токен после знака `=`:

   ```dotenv
   TOKEN=ваш_токен
   ```

4. Сохраните файл и запустите автотесты через IDE.
